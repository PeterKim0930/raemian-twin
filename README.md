# 래미안 트윈 CCTV

래미안 주차장 디지털 트윈의 CCTV 배치와 시야를 비교하는 웹 뷰어입니다. 평면도와 시뮬레이션 사진으로 기존 11대 배치와 14대 재배치안을 살펴볼 수 있습니다.

**페이지 접속:** [CCTV 배치·시야 비교 열기](https://peterkim0930.github.io/raemian-twin/)

## 주요 기능

- 대상 높이, 가시 기준, 차량 배치에 따른 CCTV 시야와 커버율 비교
- 카메라 선택 시 해당 시야와 촬영 이미지 확인
- 차량 선택 시 해당 차량을 볼 수 있는 카메라별 이미지와 차량 위치 표시
